# Day 05 - CSV Sales Report Automation

## Project Overview

This project is a Python-based CSV data processing and reporting tool.

It reads sales data from a CSV file, calculates the total sale for each record, generates a summary report, and creates a new CSV report automatically.

## Features

- Read sales data from CSV
- Calculate total sales
- Calculate total revenue
- Calculate average sale
- Find highest sale
- Find lowest sale
- Generate a CSV report
- Handle common file and data errors

## Project Structure

## Requirements

- Python 3.x
- No External Packages required

## How to run

Inside the Project Folder. Run the Command:

```
python sales_report.py
```
